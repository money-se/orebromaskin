När något ersätts

Utrustning som inte längre används kan fortfarande ha ett värde

När en verksamhet byter maskinpark, stänger en del av verksamheten, flyttar eller rensar lager blir äldre utrustning ofta stående.

Vi försöker se vad som kan repareras, säljas vidare, användas som reservdelar eller få ett nytt användningsområde.

Exempel på situationer

✓ Maskiner som ersatts

✓ Äldre reservdelslager

✓ Verkstadsutrensning

✓ Lantbruksutrustning som inte används

✓ Blandade partier vid flytt eller omorganisation

Så fungerar det

1

2

4

Vi planerar överlämning

Transport och praktiskt upplägg bestäms efter överenskommelse.

Geografiskt område

Pålsboda som bas – större affärer kan motivera längre resor

Närke och Örebroregionen är vårt kärnområde. Vid större partier, värdefullare maskiner eller särskilt intressanta objekt kan vi även åka mot exempelvis Karlskoga, Motala, Norrköping eller Karlstad.

Vanliga frågor

För företag och verksamheter

Köper ni hela verkstads- eller lagerpartier?

Ja. Vi kan bedöma flera maskiner, reservdelar och andra relevanta objekt på samma gång.

Måste allt fungera?

Nej. Äldre, trasiga och ofullständiga objekt kan fortfarande ha värde genom återbruk eller reservdelar.

Behöver vi inventera allt först?

Nej. Börja gärna med översiktsbilder. Vi kan därefter säga vilka delar vi vill veta mer om.

Kan ni ordna transport?

Transport kan ordnas efter överenskommelse för objekt och partier som vi köper. Omfattning och avstånd påverkar upplägget.
